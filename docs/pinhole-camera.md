# 小孔成像 · 双板自由探究

## 结构与交互

- `models/pinhole-camera.html` 基于独立 V6 版本迁入。完整 GLB 模型内嵌，离线运行，器材由蜡烛、带实际开口的孔板、半透明光屏、支架与滑轨组成，取消暗箱。
- 孔板固定。左键拖动光源或光屏可沿滑轨分别调节物距与像距，也可使用滑块。
- 实际开孔面积可调范围为 0.3～7854.0 mm²，滑块采用对数刻度。切换圆孔、方孔或三角孔时，三种开口的实际面积相同。默认开孔面积为 966.0 mm²。三维画面中的正视放大窗同步显示孔形。
- 左键空白旋转，旋转角度以鼠标 `dx,dy` 的负方向更新，等同 OrbitControls 正向 rotateSpeed；右键或 Shift+左键平移、滚轮缩放。鼠标右移时可见的近侧标记向右移动。板件拖动优先于视角旋转。

## 纸筒暗箱

- 从「选择实验」进入「纸筒暗箱」。蜡烛可左右拖动，纸筒前端开孔，后端描图纸接收倒立的火焰像。「剖开看光路」显示纸筒内的边缘光线，「关灯」增加暗处观察对比度，「重新开始」复位。返回双板实验时恢复原来的设置。

## 物理模型与限制

- 几何近似 `像高/物高 = v/u`；点光源的几何光斑面积为 `A(1+v/u)²`，其中 `A` 是实际开孔面积。孔形影响光斑轮廓，透光量按开孔面积计算。用光粒子示意前向传播，典型光路表示通过孔的射线。
- 默认开启「清晰演示」，在初始开孔面积下切换孔形仍显示大小一致的倒立像，继续增大开孔面积时逐渐过渡至实际孔形的几何光斑叠加。取消勾选可直接显示几何光斑效果。亮度衰减以光源到光屏总距离估算，模型采用几何光学近似。

- 展开「为什么小孔更清晰？」后，在左侧三维场景依次显示 F 光源或蜡烛火焰上 A、B、C 三个物点的边缘光线和对应光斑。原先选择点光源时，演示临时使用 F 光源。切换大孔和小孔可比较光斑重叠情况，收起演示后恢复此前的探究设置。开孔面积读数显示在三维场景顶部。
