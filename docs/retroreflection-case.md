# 逆反射 · 自行车与高速公路（V9 发布版）

- 教学目标：观察车灯与无源反光的关系；区分教材二维两次反射和真实三维三面角锥；调节入射角、观察法线和反射角。
- 引擎与单位：本地 Three.js r160 单实例；生活场景长度 m，光学角度计算使用 rad，显示 °；二维 SVG 使用图形坐标。
- 采用资源：参考 camera-navigation（1.0.0）的手动接管原则；本案例沿用自身指针事件控制器，不新增公共资源或独立渲染器；物理材质参考现有玻璃材质规范。未声称直接调用 LabKit API。
- 连接关系：车辆、反光装置以场景父组及局部坐标组装；二维 SVG 与三维光线各自使用同一页的几何计算结果。
- 物理状态：逐面求交、反射定律、斯涅尔定律；实心角锥 n=1.49，临界角约42.2°，镀膜为理想反射。两次／三次反射方向反转仅在满足相应条件时成立。夜间亮度和道路设施间距是定性教学简化，不作为实测照度或工程设置标准。资料链接见案例科学依据。
- 镜头：逐次光学事件自动正视入射平面；每步停留4.5 s；手动指针及滚轮操作停止自动演示。驾驶员视角保持眼点固定，双指移动改变观察朝向，缩放改变视场。
- 局部观察：设备背面观察、拆解和无色材质；二维 SVG 可缩放平移，三维使用相机近看；没有单独的仪表读数窗口。
- 验收：本地 Chromium 模拟触屏通过自行车、高速公路、装置结构、教材二维、三维探究五页双指缩放和平移，以及手动打断自动演示；V9 页面跳转与角锥三次反射计算通过。WebGL 初始化失败，使用替代渲染器验证程序与交互，未验收实际三维画面及真实触屏硬件。封面取自用户实际运行 V7 的高速公路驾驶员视角截图（该场景在后续版本保留），缩小转换为 WebP，不是生成图。当前环境无法通过 git 拉取仓库，未执行仓库全量四项测试或离线批量导出；保留独立 HTML 发布版，仓库版改为引用本地共享 r160。未变更公共资源。
