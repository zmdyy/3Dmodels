# 力与平衡实验室

[在线实验](https://zmdyy.github.io/3Dmodels/models/force-balance-lab.html) · [单文件源码](../../../models/force-balance-lab.html)

| 项目 | 说明 |
|---|---|
| 教学目标 | 观察力引起的形变和运动变化，练习弹簧测力计读数及重心定位，比较惯性、平衡、摩擦与等效合力。 |
| 引擎与单位 | 内嵌 Three.js r160、视角导航及场景脚本。实验采用 m、N、s，仪器读数按实验使用 N、cm 或 mm。 |
| 视角 | 默认、正视、俯视。支持拖动旋转、滚轮或双指缩放、右键或双指平移。 |
| 局部读数 | 弹簧伸长尺及测力计使用跟随指针的 SVG 刻度。桌面形变显示反射光斑的初始和当前位置。 |
| 物理简化 | 磁力、橡皮泥塑性保留、公交乘客姿势和部分接触过程用于定性观察。玻璃瓶用体积变化与细管截面积求液面变化，桌面用两次镜面反射求屏上光斑位置。 |
| 连接与状态 | 横梁导套约束压杆，压杆带动压板。教材拉伸比较由同一位置标记连接双力组与单力组，测力计、刻度窗及示数共用实验状态。 |
| 离线与封面 | HTML 内嵌运行资源，可用文件方式打开。首页封面取自当前版本「力与形变」的实际 WebGL 画面。 |
