# 运动与能量探究实验室 · 复用与验收记录

| 项目 | 记录 |
|---|---|
| 教学目标 | 六阶段：阻力与运动、动能探究、U形轨道、机械能转化、阻力与能量、过山车拓展。观察等时点距、坡底速度、滑块位移、转折高度与能量变化；控制变量。 |
| 引擎与单位 | Three.js r160，m/N/s/rad，Y轴向上；过山车为独立内嵌 iframe，独立场景，不混用引擎实例。 |
| 采用资源 | 内嵌 camera-navigation 1.0.0（navigation.js）；参考 car-speed 的等时运动带呈现；复用此前离线小车、轨道、支撑及 SVG 读数实现。未修改公共资源。 |
| 连接关系 | 中央承重管下方支撑；水平起跑线与 0 m 对齐；蓝色滑块后缘初始在 2 m，位移从其前缘计算，色带深度检测开启并贴合板面。 |
| 物理状态 | 斜坡无阻力、忽略轮转动惯量，v0=√(2gh)。水平面采用等效阻力 μmg（棉布 .30、木板 .12、理想无阻力 0），数值为教学设定。动能实验完全非弹性碰撞 u=mv0/(m+M)，碰撞后 a=μMg/(m+M)，s=u²/(2a)，滑块质量1 kg，μ=.30；释放高度 .5/1/1.5 m，小车质量1–2.5 kg。位移只能间接比较动能，改变小车质量也会改变碰撞传递比例。U形轨道以最低点为势能零点；机械能及耗散能量共用状态。圆环为理想无防脱轮模型，横向错轨仅用于显示。 |
| 新增与依据 | 统一运动带、测速标签、板面位移覆盖、可拖动比较窗、单次播放保留点迹。最新版按用户要求删除动能对比条右侧参数文字，距离写在色带内；短色带时在终点旁显示。材质为程序化教学模型。 |
| 镜头 | 默认、正视、俯视、运动带视角；复用手动旋转、滚轮和双指缩放平移。 |
| 局部放大及字体 | 主视图与 SVG 读数；不强制独立仪表放大窗。字体采用系统回退。 |
| 验收 | 上传源文件 Git blob b4063a983f89e6457bad84601280448c3a612427，与本地最新 HTML 完全相同。node --check 通过；Chromium 二维备用模式测试主页面六阶段入口、12组高度/质量运动计算、滑块初始后缘2 m、终点位移及对比窗内距离文字，无页面脚本异常及外部网络请求。圆环入口为内嵌子页，本轮未完整回归其内部交互。封面为实际运行的U形轨道二维备用模式截图缩小。当前环境不能启用 WebGL，未验收真实三维和触屏实机；仓库完整公共资源回归命令本轮未运行（本地无法克隆仓库），公共组件未修改。 |
