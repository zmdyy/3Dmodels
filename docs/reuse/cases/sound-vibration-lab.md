# 声音与振动实验室

| 项目 | 说明 |
| --- | --- |
| 教学目标 | 用乒乓球的摆动判断音叉在振动，比较声音在不同介质中的传播，探究音调、响度和音色，再用回波时刻推算距离。 |
| 引擎与单位 | 单文件内嵌 Three.js r160。计算使用米、秒和弧度，界面按实验切换厘米、毫秒或微秒。演示尺寸和慢放倍率单独设置。 |
| 视角复用 | 采用 LabKit 的视角和手势设计，支持旋转、滚轮缩放、双指缩放和平移。课堂可切换正视、俯视、默认视角和局部特写。 |
| 声源与接触 | 音叉叉股呈现微振动。程序根据叉股与小球的间隙及相对速度计算接触，小球弹开后按摆运动衰减。钢尺、琴弦和铃声由浏览器合成。 |
| 回波与成像 | 固定收发点用声速乘往返时间再除以二。行车测山崖分别计算发射和接收位置，固定测速仪用两次反射的位置差和时间差求车速。超声成像逐线绘制理想界面回波。 |
| 数据来源与近似 | 音叉、悬臂梁和拨弦振型的参考资料见 HTML 末尾。地形和超声波束为教学模型，图像为模拟体回波图。 |
| 首页封面 | 音叉振动并弹开乒乓球时的实际 Chromium WebGL 画面，截图时隐藏控制界面，裁为 960×540。 |
