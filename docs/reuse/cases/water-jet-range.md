# 水从哪里喷得更远？ · 复用与验收记录

- 教学目标：比较液体压强、出水速度、下落时间、水平射程；通过三孔、移动单孔、改变水面及容器高度探究最大射程。
- 引擎与单位：Three.js r160，m / N / s / rad，Y 轴向上，射流沿 +X。单文件内嵌原公共组件，未修改公共资源。
- 复用：camera-navigation 1.0.0（navigation.js）；glass-beaker 1.0.0（glassware.js）；svg-scale 1.0.1（svg.js）；classroom-typography 1.0.0（typography.css）。均为已有资源，非新增公共 API。
- 连接：玻璃容器底座与平台对齐，孔口位于容器 +X 壁；射程从孔口水平坐标计算。
- 物理：h 为孔距液面深度，y 为孔距落点高度；p=ρgh，v=√(2gh)，t=√(2y/g)，L=2√(hy)。自然排水默认开启；敞口、小孔、水平理想射流，忽略黏性和空气阻力，流量采用理想出口速度。自然下降过程按准稳态轨迹显示，不模拟完整瞬态流体。
- 新增：带孔容器壁、射流、落点靶标和留痕、测量记录、射程曲线；水流粒子、飞溅及地面留痕为教学增强。
- 镜头：默认、正视、旋转、缩放、双指平移；无独立局部放大窗。
- 字体：复用课堂字号，SVG 刻度与同源读数，字体依赖系统回退。
- 验收：本地 HTML 与提交 blob SHA 1f33815a98d574e74cb64724e7c0e5f51d63ec02 完全一致。当前浏览器无法启用 WebGL，实际运行二维备用模式，三孔恒水位射程约 27.2、31.7、24.8 cm（下、中、上）。封面从备用模式实际运行的 SVG 取样裁切，非 3D 截图。WebGL 与触屏实机验收及完整公共组件回归未在本轮执行。
